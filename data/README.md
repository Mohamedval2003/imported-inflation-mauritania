# Data Access

The original datasets used in this project are institutional and are not distributed in this public repository.

The analysis was conducted during an academic internship at the **National Agency for Statistics and Demographic and Economic Analysis** (*L’Agence Nationale de la Statistique et de l’Analyse Démographique et Économique — ANSADE*) in Mauritania.

## Required private files

Authorised users must place the following source files inside `data/private/` before running the notebook:

```text
data/private/
├── Historique_INPC_base_2019_Etude inflation-2025.xlsx
├── IndiceMensuel base 100=2024.xlsx
├── coellecte taux_de_change_Najeeb.xlsx
├── data (21).xlsx
└── data (22).xlsx
```

The filenames are preserved because the notebook relies on the original project configuration. The `data/private/` directory and spreadsheet files are excluded through `.gitignore`.

## Public repository policy

This repository contains only:

- Source code and methodological explanations
- Aggregated results
- Final tables and figures
- Instructions for authorised local execution

It does not contain raw institutional records or redistributable copies of the original datasets.
